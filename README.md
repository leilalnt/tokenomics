# داده‌های خام مقالهٔ توکنومیک – دانشگاه تهران

این مخزن شامل داده‌های خام مقاله‌ی «توکنومیک: شناسایی عوامل مؤثر بر موفقیت یک رمز ارز» است که برای **دانشگاه تهران** تهیه شده است. داده‌ها برای دو رمز ارز **اتریوم (ETH)** و **ورت‌کوین (VTC)** در دو فرمت **CSV** و **اکسل (xlsx.)** ارائه شده‌اند تا امکان استفاده در نرم‌افزارهای گوناگون فراهم باشد. متغیرهای مورد بررسی در این پژوهش شامل **ارزش بازار (Y)** به عنوان متغیر وابسته و **۸ متغیر مستقل** شامل حجم معاملات، نحوهٔ توزیع در کیف‌پول‌ها، قدرت و امنیت شبکه، فناوری و نوآوری، تعداد شبکه‌های قابل معامله، هزینهٔ تراکنش، قیمت پایانی و پویایی عرضهٔ در گردش است. هدف از انتشار عمومی این داده‌ها، شفاف‌سازی، تکرارپذیری و کمک به پژوهش‌های آتی در حوزهٔ اقتصاد رمز ارزها است.

| نماد | عنوان متغیر |
|------|-------------|
| Y    | ارزش بازار |
| X1   | حجم معاملات |
| X2   | نحوه توزیع در کیف پول‌ها |
| X3   | قدرت و امنیت شبکه |
| X4   | تکنولوژی و نوآوری |
| X5   | تعداد شبکه‌های قابل معامله |
| X6   | هزینه تراکنش |
| X7   | قیمت پایانی |
| X8   | پویایی عرضه در گردش |

برای استفاده، فایل‌های مورد نظر را از پوشهٔ `data/` بارگذاری کرده و در صورت نیاز به استناد، از شناسهٔ زیر استفاده کنید:
